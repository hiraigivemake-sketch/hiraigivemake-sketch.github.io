切り替えの手順

この順番が大切です。下の順にやれば、ホームページが見られなくなる時間をほぼゼロにできます。逆の順でやると、数十分つながらなくなります。

1

GitHubに、使いたいアドレスを登録する

GitHub のサイト（ブラウザ）
  1. GitHubでリポジトリ hiraigivemake-sketch.github.io を開く
  2. 上のタブ Settings → 左メニュー Pages
  3. Custom domain の欄に giveandmake-c.com と入力して Save

「DNS check unsuccessful（確認できません）」という赤い表示が出ますが、この時点では正常です。次の手順で解消します。

この作業では、いまのホームページは何も変わりません。引き続きSTUDIOの内容が表示されます。

所要：2分

2

設定ファイルを追加して送信する

Claude Code（こちらで作業します）

ステップ1が終わったら教えてください。アドレスを記憶させるためのファイルを用意し、動作確認のうえ準備します。あとは ⑥ 変更をGitHubに送る を押していただくだけです。

所要：5分

3

ドメインの向き先を変える　← ここで切り替わります

ムームードメイン の管理画面
  1. ムームードメイン にログイン
  2. 左メニュー ドメイン操作 → ムームーDNS
  3. giveandmake-c.com の行の 変更 を押す
  4. カスタム設定 の一覧が表示されます

いまある「種別A・内容 34.111.141.225」の1行を削除し、かわりに次の4行を追加します。

サブドメイン種別内容
（空欄）A185.199.108.153
（空欄）A185.199.109.153
（空欄）A185.199.110.153
（空欄）A185.199.111.153

入力できたら セットアップ情報変更 を押して保存します。

所要：10分

⚠ 絶対に消してはいけない設定があります

同じ画面に、メールのための設定が入っています。これを消すと @giveandmake-c.com 宛のメールが届かなくなります。

種別 MX　内容 mx01.lolipop.jp（優先度 50）
種別 TXT　内容 v=spf1 include:lolipop.jp ~all
種別 TXT　内容 google-site-verification=…

この3行はそのまま残してください。変更するのは「種別A」の行だけです。

不安な場合は、変更前の画面をスクリーンショットで撮っておくと安心です。万一のときも元に戻せます。

4

切り替わったか確認する

ブラウザ

設定の反映には 10分〜1時間ほどかかります（長いと数時間）。ときどき https://giveandmake-c.com を開いて確認してください。

新しいホームページが表示されれば成功です。見分け方は、スタッフ紹介ページに9名全員が載っているかです。

古いまま表示される場合は、ブラウザで ⌘+Shift+R（Windowsは Ctrl+F5）を押して読み込み直してください。

所要：待ち時間 10分〜1時間

5

鍵マーク（暗号化）を有効にする

GitHub のサイト

ステップ4が確認できたら、もう一度 Settings → Pages を開きます。

Enforce HTTPS というチェック欄が押せるようになっているので、チェックを入れます。

これでアドレスバーに鍵マークが付き、安全な通信になります。証明書の準備に最大1時間かかることがあり、それまではチェックが押せません。その場合は時間をおいてからお試しください。

所要：1分（準備待ちが最大1時間）

6

1〜2週間ようすを見てから、STUDIOを解約

STUDIO

切り替えてすぐには解約しないでください。問題が起きたときにすぐ戻せるよう、しばらく残しておきます。

1〜2週間、次の点を確認して問題がなければ解約して構いません。

  • 各ページが正しく表示されるか
  • お問い合わせフォームから実際に送信して、届くか
  • スマートフォンでも問題ないか
  • Google検索から来たときも正しく表示されるか

所要：様子見1〜2週間

切り替え作業の手順

  1. Googleフォームを作り、設定を済ませたこれが終わるまで切り替えないでください
  2. ムームーDNSの画面をスクリーンショットで保存した万一のとき元に戻すため
  3. GitHubで Custom domain に giveandmake-c.com を登録した赤い警告が出ますが正常です
  4. Claude Code に連絡し、設定ファイルを送信した⑥ 変更をGitHubに送る
  5. ムームーDNSで A レコードを4つに差し替えたMXとTXTの3行は残す
  6. giveandmake-c.com を開いて、新しいサイトが出たスタッフ9名が目印
  7. GitHubで Enforce HTTPS にチェックを入れた鍵マークが付きます
  8. フォームから実際に送信して、届くことを確認したいちばん大事な確認です
  9. 1〜2週間後、STUDIOを解約したあわてず、確認してから

よくある質問

本当に無料で公開し続けられますか
はい。GitHub Pages は公開リポジトリであれば無料で、容量・通信量とも通常の事業所サイトには十分です。ドメイン代（年間数千円）とメール代だけが継続費用になります。
ホームページのアドレスは変わりますか
変わりません。https://giveandmake-c.com のままです。ブログ記事の個別アドレスもすべて同じなので、検索順位や既存のリンクへの影響もありません。
メールは大丈夫ですか
今回変更するのは「ホームページの向き先」だけで、メールの設定は触りません。ただし操作ミスで消してしまうと届かなくなるため、作業前のスクリーンショットをおすすめしています。
切り替えに失敗したら戻せますか
戻せます。ムームーDNSのAレコードを 34.111.141.225 に戻せば、STUDIOの表示に戻ります。だからこそSTUDIOをすぐ解約しないことが大切です。
www を付けたアドレスはどうなりますか
現在 www.giveandmake-c.com は設定されていないため、いまも使えていません。必要であれば追加できますので、ご希望があればお知らせください。
途中で分からなくなったら
その画面のスクリーンショットを Claude Code に貼り付けてください。どこを押せばよいかお答えします。作業を中断しても、ホームページが壊れることはありません。
