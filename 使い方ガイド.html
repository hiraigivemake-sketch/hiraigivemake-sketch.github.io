ホームページの
使い方ガイド

むずかしい操作はありません。フォルダを開いて、アイコンをダブルクリックするだけです。パソコンに詳しくない方でも、この順番どおりに進めれば編集できます。

まず覚えるのは これだけ です。
デスクトップの kuricare-site フォルダを開き、① 編集をはじめる をダブルクリック。

編集のしかた

1

デスクトップの「kuricare-site」フォルダを開く

ホームページに関するものは、すべてこのフォルダの中に入っています。フォルダごと移動したりコピーしても大丈夫です（中身のファイル名は変えないでください）。

2

① 編集をはじめる をダブルクリック

黒い画面が出たあと、少し待つとブラウザで編集画面がひらきます。黒い画面は閉じずにそのままにしておいてください。編集中はずっと開いたままにします。

※ 初回だけ「開いてもよろしいですか？」と聞かれることがあります。右クリック →「開く」を選んでください。

3

左のメニューから、直したいものを選ぶ

左側に「ページ」「記事」「素材・設定」「メンテナンス」が並んでいます。直したいものをクリックしてください。

4

見出しをクリックして開き、文字を書きかえる

ページの中身は「メインビジュアル」「Serviceセクション」のように、見た目の場所ごとにまとまっています。直したい見出しをクリックすると開きます。

書きかえたら、画面いちばん下の 「保存する」 を押してください。押し忘れると反映されません。

5

できあがりを確認する

画面右上の 「サイトを見る」 を押すと、実際のホームページの見た目で確認できます。おかしければ、また編集画面にもどって直せば大丈夫です。

※ この編集画面はご自身のパソコンの中だけで動いています。保存しても、まだインターネット上のホームページは変わりません。

写真・イラストを差し替える

1枚の写真を変える

写真の項目には、いまの画像と 「画像を選ぶ」「外す」 のボタンが並んでいます。「画像を選ぶ」を押すと一覧から選べ、その画面の右上からパソコンの写真をその場でアップロードすることもできます。

複数の写真が並ぶところ

トップページのスタッフ写真のように何枚か並ぶ項目は、写真の下の ←→ で並べ替え、✕ で外し、＋追加 で増やせます。

まとめてアップロードする

左メニューの「画像ライブラリ」に、写真をドラッグ＆ドロップすればまとめて追加できます。使っていない画像には「未使用」と表示されるので、整理の目安になります。

ブログを書く

新しい記事を書く

左メニューの「ブログ」→ 「＋ 新しく追加」。タイトル・日付・サムネイル・本文を入れて保存すれば、ブログ一覧とトップページに自動で並びます。

記事を消す

記事の編集画面をいちばん下までスクロールすると「この記事を削除する」があります。完全には消えず content/_trash に移動するので、まちがえても戻せます。

編集を終わる

ブラウザを閉じたあと、黒い画面も閉じてください。次に編集するときは、また ① 編集をはじめる をダブルクリックします。

ほかのアイコン

② ホームページを見る

編集画面を開かずに、できあがりだけを確認したいときに使います。

③ 点検する　— 月1回おすすめ

リンク切れや、表示されない写真がないかを自動で調べます。「✅ 問題は見つかりませんでした」と出れば安心です。

④ バックアップを取る　— 月1回おすすめ

その時点の内容をまるごと保存します。まちがえて消してしまったときは、backups フォルダの中から戻せます。

⑤ 共有用にまとめる

他のパソコンに渡すためのファイル（ZIP）をデスクトップに作ります。詳しくは下の「他のパソコンで使う」をご覧ください。

他のパソコンで使う

このホームページは フォルダごと持ち運べる つくりです。
Mac ならそのまま、Windows なら Python を1度だけ入れれば、どのパソコンでも編集できます。

A

1回だけ渡す

⑤ 共有用にまとめる をダブルクリックすると、デスクトップに kuricare-site_共有用_日付.zip（約40MB）ができます。

これを AirDrop・USBメモリ・ギガファイル便などで渡してください。受け取った人は ZIP を展開してデスクトップに置き、Mac なら ① 編集をはじめる.command、Windows なら Windows用 フォルダの中の ① 編集をはじめる.bat をダブルクリックするだけです。

B

いつも最新を全員で共有する（事業所内におすすめ）

kuricare-site フォルダごと、OneDrive や Google ドライブの共有フォルダに置きます。以後、誰が編集しても全員のパソコンに反映されます。

※ 同時に編集しないでください。2人が同時に「保存する」を押すと、片方の変更が消えることがあります。「いまから触ります」と一声かけるルールにしておくと安全です。

※ OneDrive の場合は、フォルダを右クリック →「このデバイス上で常に保持する」にしてください。クラウド上だけに置かれていると起動できません。

C

複数人できちんと管理する

GitHub というサービスで管理すると、誰がいつ何を変えたかが残り、公開の自動化もできます。必要になったら Claude Code に相談してください。

Windows で使うときの準備

Microsoft Store で「Python 3」を検索してインストールしてください（無料・5分ほど）。Mac は何も要りません。

まだ残っている作業

困ったとき

ダブルクリックしても何も起こらない
Mac … 右クリック →「開く」を選び、確認画面で「開く」を押してください。安全機能によるものです。
Windows … 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押してください。
編集したのに、見た目が変わらない
画面下の「保存する」を押し忘れている可能性があります。もう一度押してください。確認画面の再読み込み（⌘+R）も試してください。
まちがえて消してしまった
記事なら content/_trash フォルダの中にあります。それ以外は backups フォルダのバックアップから戻せます。
赤い字のエラーが出た
画面に出ている文字をそのままコピーして、Claude Codeに「kuricare-siteでこう出ました」と貼りつけてください。
もっと大きく変えたい
Claude Codeに話しかけてください。「トップページのキャッチコピーを○○に変えて」「スタッフを1人追加して」のような言い方で伝わります。
