========================================
 Windows でホームページを編集する方法
========================================

【1】 準備（最初の1回だけ）

  Python をインストールします（無料・5分ほど）。

    1. スタートメニューから「Microsoft Store」を開く
    2. 検索欄に「Python 3」と入力
    3. 「Python 3.12」など新しいものを選んで「入手」を押す

  ※ すでに入っている場合は不要です。
  ※ 入っているか分からないときは、下の「③ 点検する.bat」を
     ダブルクリックしてみてください。案内が出ます。


【2】 使い方

  このフォルダの中のファイルをダブルクリックするだけです。

    ① 編集をはじめる.bat
        文章・写真・ブログを編集します（いちばんよく使います）

    ② ホームページを見る.bat
        できあがりだけ確認します

    ③ 点検する.bat
        月1回。リンク切れや写真の抜けを自動チェック

    ④ バックアップを取る.bat
        月1回。まちがえたときに戻せるよう保存

    ⑤ 共有用にまとめる.bat
        他のパソコンへ渡すZIPをデスクトップに作ります

    ⑥ 変更をGitHubに送る.bat
        直した内容をインターネット上のホームページに反映します
        （GitHubと連携している場合のみ）

  ※ _python.bat は他のファイルが内部で使うものです。
     ダブルクリックしないでください。


【3】 「WindowsによってPCが保護されました」と出たら

  「詳細情報」→「実行」の順に押してください。
  自分たちで作ったファイルなので問題ありません。


【4】 GitHubと連携して使う場合

  1. GitHub Desktop をインストールして、同じアカウントでログイン
     （https://desktop.github.com）
  2. File → Clone repository → hiraigivemake-sketch.github.io を選ぶ
  3. 保存先をデスクトップにして Clone

  【毎回のルール】
    編集を始める前に、GitHub Desktop で
    「Fetch origin」→「Pull origin」を押して最新にしてください。
    これを忘れると、他のパソコンでの変更が消えることがあります。

  編集が終わったら「⑥ 変更をGitHubに送る.bat」を実行します。


【5】 困ったとき

  画面に出ている文字をそのままコピーして、
  Claude Code に貼り付けて相談してください。

  詳しい説明は、1つ上のフォルダにある
  「使い方ガイド.html」「GitHub公開の手順.html」を
  ダブルクリックすると開きます。
