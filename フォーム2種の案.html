作り方A：自動で作る（おすすめ・10分）

2つのフォーム・回答用スプレッドシート・通知メール・自動返信が、いっぺんに作れます。質問を1つずつ手で入力する必要はありません。

1

Apps Script を開く

Googleにログインした状態で script.google.com を開き、新しいプロジェクト を押します。

2

スクリプトを貼り付ける

フォルダ内の tools/create_google_forms.gs をテキストエディタ（メモ帳など）で開き、中身をすべてコピーします。

Apps Scriptの画面に最初から書かれているコードをすべて消してから、貼り付けてください。

3

実行して許可する

上部の関数名が createForms になっていることを確認し、▶ 実行 を押します。

初回だけ許可を求められます。権限を確認 → アカウントを選択 → 詳細 → （安全でないページ）に移動 → 許可 の順に進んでください。

ご自身で作ったスクリプトのため、この警告は正常です。フォームを作り、メールを送るための許可を求めています。

4

実行ログをコピーして送る

画面下に 実行ログ が表示されます。その内容をすべてコピーして、Claude Code に貼り付けてください。

ホームページ側の設定に必要な情報（フォームのアドレスと、項目ごとの受付番号）が入っています。受け取り次第、こちらで設定します。

作り方B：手作業で作る

自動がうまくいかないときは

forms.google.com で空白のフォームを2つ作り、上の「案①」「案②」のとおりに質問を入力してください。

  • 「記述式（1行）」… 記述式 を選ぶ
  • 「記述式（複数行）」… 段落 を選ぶ
  • 選択肢が丸印のもの … ラジオボタン を選ぶ
  • 「プルダウンから選択」… プルダウン を選ぶ
  • 必須と書かれた項目は、右下の「必須」をオンにする

できあがったら、2つのフォームのアドレス（URL）を Claude Code に送ってください。残りはこちらで設定します。

作ったあとの流れ

こちらで行うこと

  • ホームページのフォームを、作成したGoogleフォームにつなぐ
  • 実際に送信して、スプレッドシートとメールに届くか確認
  • 見た目が今のままであることを確認

訪問される方から見た画面は、いまと何も変わりません。Googleフォームの画面に飛ばされることもありません。

そのあと

フォームが動くようになれば、本番のホームページへの切り替えに進めます。手順は「本番切り替えの手順」をご覧ください。

よくある質問

費用はかかりますか
かかりません。Googleフォーム・スプレッドシート・自動返信メールのすべてが無料です。1日あたりの送信通数にも、通常の事業所であれば十分な余裕があります。
回答はどこに貯まりますか
Googleドライブに自動で作られるスプレッドシート（「クリケア｜お問い合わせ 回答」など）に1行ずつ追加されます。あとから並べ替えや検索ができ、Excel形式で書き出すこともできます。
通知メールの宛先を変えられますか
変えられます。スクリプトの上のほうにある NOTIFY_EMAIL の行を書き換えてください。複数名に送ることも可能です。ご希望があればこちらで設定します。
自動返信は止められますか
止められます。スクリプトの SEND_AUTO_REPLY を false に変えるだけです。文面の変更も同じ場所でできます。
いたずら送信が心配です
まずはこのまま運用し、もし迷惑な送信が続くようであれば対策を追加できます（送信数の制限や、簡単な確認項目の追加など）。ご相談ください。
あとから項目を増やせますか
増やせます。ただしホームページ側の設定も合わせて変更する必要があるため、変更されたらお知らせください。
